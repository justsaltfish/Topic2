## Results 1. DDPM 生成的 160 bp 增强子序列质量评价

本研究以长度为 160 bp 的增强子序列为对象，采用 DDPM 建立从序列分布学习到新序列生成的计算流程。模型基于[待核实 M01：最终训练数据、物种及筛选条件]训练，使用[待核实 M02：最终 checkpoint 与采样设置]生成[待核实 M03：样本数及独立重复数]条序列，并与[待核实 M04：真实参照集合]进行比较。评价覆盖序列组成、调控 motif 分布及序列多样性，以检验生成结果是否同时保留真实增强子的统计特征和区别于已有序列的变化空间（Fig. 1A）。

GC 含量与 k-mer 频率用于刻画生成序列和真实序列的组成关系。两组序列的 GC 分布分别为[待核实 M05：中心位置、离散程度与分布差异]；在相同计数规则下，长度为[待核实 M06：最终 k 值]的 k-mer 频率相关系数为[待核实 M06：相关系数及独立重复间变异]（Fig. 1B–C）。GC 的整体分布与 k-mer 的局部组成共同构成评价依据，其结果需结合参照集合的划分方式解释，以区分分布学习与对训练样本的重复利用。

调控特征的比较采用统一的 motif 数据库和扫描设置，对真实序列与生成序列计算 motif 命中分布。在[待核实 M07：数据库版本、背景模型、阈值及计数规则]下，两组序列的 motif 分布差异为[待核实 M07：最终分布指标和代表性 motif 的变化]（Fig. 1D）。与碱基组成评价结合后，该分析用于判断生成序列是否保留参照增强子的 motif 统计特征。motif 命中描述序列模式的存在，其功能效应需与独立的活性证据区分。

生成序列的内部相似度为[待核实 M08：指标定义及分布]，与训练集及独立真实参照集合的相似度分别为[待核实 M08：对应分布及近重复比例]（Fig. 1E）。在全部输出序列中，唯一序列比例为[待核实 M09：比例]，长同聚物或低复杂度序列比例为[待核实 M09：阈值、比例及过滤保留率]（Fig. 1F）。这些指标与 GC、k-mer 和 motif 的比较共同用于界定生成序列的质量，最终对分布一致性、多样性和新颖性的判断以匹配本模型版本的完整数据为依据。

## Results 2. 预测器引导下的增强子定向生成

在 DDPM 生成流程中，本研究使用序列活性预测器提供定向优化信号，并比较无引导、UP、DOWN 和 BOTH 三种引导设置（Fig. 2A）。预测器对应[待核实 M10：物种、UP/DOWN 条件含义、分数尺度、模型和独立测试集]，其测试表现为[待核实 M10：本文实际模型的 PCC 及其他误差指标]。引导和评价使用的模型关系为[待核实 M11：是否为同一预测器及是否有独立评价器]，据此界定预测分数优化的解释范围。

各模式在[待核实 M12：共同 checkpoint、采样步数、初始噪声、种子和样本数]条件下进行比较。无引导序列的 UP/DOWN 预测分布为[待核实 M13：均值、中位数及离散程度]；相应引导后的分布为[待核实 M13：各模式的预测统计与效应量]（Fig. 2B）。若使用相同初始噪声形成逐样本配对，引导变化以对应样本的预测差值及改善比例描述；若实验为独立采样，则按实际设计报告群体差异。比较结果的置信区间与独立重复数为[待核实 M14：统计汇总与重复层级]。

BOTH 引导以两个预测维度的联合表现进行评价。按照[待核实 M15：阈值来源、数值、单位及比较符号]，无引导与 BOTH 引导的双目标达标数量分别为[待核实 M16：数量及各自分母]，对应比例为[待核实 M16：比例及置信区间]（Fig. 2C–D）。二维预测分布用于展示两个维度的联合变化，同时避免仅用分数之和掩盖单一目标的下降。全部模式使用相同的阈值来源，阈值敏感性分析单独列于补充材料。

引导配置的比较涵盖[待核实 M17：纳入本文的引导强度、调度和 checkpoint 范围]。各设置的预测活性与序列质量变化为[待核实 M17：统一协议下的扫描结果]（Fig. 2E）。最终配置依据[待核实 M18：预先确定的主指标、质量门槛和选择规则]确定，以区分训练损失、预测均值、双目标达标率及序列分布质量对应的不同优化方向。完整扫描及配置表列于 Table S5。

引导后的序列采用与无引导结果一致的 GC、k-mer、motif、相似度和复杂度评价。全部生成样本的质量变化为[待核实 M19：各指标及过滤前样本量]；满足质量门槛的保留率及其达标率分别为[待核实 M19：保留率、分母和达标比例]（Fig. 2F）。活性统计与质量统计共同限定引导结果的有效范围。本文计算结果描述生成序列在预测器评分上的定向变化，对实测增强子功能的判断需由独立证据支持。

## Computational Methods

### 数据来源、划分与序列表示

研究对象为 160 bp 增强子序列。最终数据来源、筛选条件、物种和样本规模为[待核实 M01：数据及其版本]。数据按照[待核实 M04：划分策略及各集合规模]组织为训练、验证和测试集合，近重复序列的处理规则为[待核实 M08：相似度阈值与集合隔离方法]。生成质量比较所用真实参照集合的来源及其与训练集的关系单独记录，以保证分布一致性与样本记忆的评价具有明确参照。

输入序列采用[待核实 M20：编码顺序、张量维度、数值范围、N 和非法字符处理]转换为模型表示。连续生成输出经过[待核实 M20：解码方式和并列概率处理]恢复为 DNA 序列，长度和字符合法性检查的实际结果记录于 Table S1。序列去重、低复杂度筛选及其发生在评价前还是评价后，由对应实验配置明确记录。

### DDPM 训练与无引导采样

DDPM 的通用方法依据 Ho、Jain 与 Abbeel 的原始研究[1]。本研究的最终实现为[待核实 M02：模型架构、代码版本和 checkpoint]；训练目标、前向噪声过程和噪声调度为[待核实 M21：与实际代码对应的定义]。优化器、学习率、batch size、训练长度、随机种子和模型选择规则均记录于 Table S1，不依据其他模型分支或另一篇论文补填参数。

采样从[待核实 M02：初始噪声分布]出发，经[待核实 M02：实际采样算法及步数]获得连续序列表示，再按照上述解码规则生成 160 bp 序列。每个条件的生成数量和独立重复数为[待核实 M03：数量、重复数与种子]。模型选择使用[待核实 M18：验证指标及最低质量门槛]，最终测试数据参与选择的情况须明确说明。

### 活性预测器与引导流程

活性预测器以序列表示为输入，输出对应物种和实验条件下的数值评分。本文使用的模型架构、checkpoint、训练标签变换、测试集隔离和误差指标为[待核实 M10：模型与验证信息]。UP/DOWN 名称的实验含义与评分单位按原始数据定义，不能根据名称推定为提高或降低活性。

梯度引导的通用思想参考 Dhariwal 与 Nichol[2]；原文针对图像分类器的结果不作为本文增强子性能证据。本文实际采用的活性回归引导需要核实预测器接收的表示、求梯度的位置、目标函数、梯度缩放、更新顺序及时间调度[待核实 M22：与引导源码一致的公式和步骤]。UP、DOWN 和 BOTH 的目标定义及多目标权重为[待核实 M22：实际配置]。无引导条件与引导条件的 checkpoint、采样预算、初始噪声、随机种子及是否配对由 Table S1 明确记录。

### 序列质量与预测活性评价

GC 含量以每条序列中的 G 与 C 数量除以有效碱基长度计算；有效长度、N 处理及输出合法性仍需与实际代码核对[待核实 M20]。k-mer 分析的 k 值、正反链处理、计数归一化、相关性计算单元及全零频率处理为[待核实 M06：评价定义]。序列相似度采用[待核实 M08：算法、归一化规则、搜索参照及抽样预算]。生成集合内部相似度、与训练集的最近邻相似度及与独立真实集合的相似度分别报告。

motif 分析使用[待核实 M07：数据库及版本]，在相同背景模型、扫描阈值和计数规则下比较真实及生成序列。Wasserstein 距离若被采用，需明确其比较对象、取值支撑、归一化和权重[待核实 M07]。复杂度评价使用[待核实 M09：同聚物长度阈值、重复定义和复杂度指标]。全部生成样本与质量过滤后样本的统计分开报告，并记录过滤保留率。

对使用共同初始噪声构成配对的序列，预测差值定义为引导后分数减对应无引导分数，改善判定按[待核实 M22：目标方向]执行。对于独立采样条件，报告组间分布差异，不构造虚假的逐样本差值。双目标达标比例为同时满足两个冻结阈值的序列数除以指定评价集合的样本数；阈值来源、比较符号及全样本或筛选后分母为[待核实 M15、M16、M19]。

### 统计与可复现性

统计汇总的单位、随机种子数量、区间估计方法、假设检验、效应量及多重比较处理为[待核实 M14：实际分析方案]。同一次运行生成的序列不是独立训练或采样运行的替代重复。最终模型、数据、参数和分析代码的版本，以及软件、硬件、耗时和文件校验信息记录于[待核实 M23：可复现记录]。本文计算评价描述序列分布和预测评分的变化，预测器在训练分布之外的可靠性与独立评价结果需随实际证据说明。
