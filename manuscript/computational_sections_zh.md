# 160 bp 增强子生成：计算部分核验稿

版本日期：2026-10-08。正文已依据既有序列、逐样本预测、代码和日志核验更新。最终模型、阈值及投稿期刊仍待作者确认；历史记录冲突及统计限制另列核对清单。

## Results 1. DDPM 生成的 160 bp 增强子序列质量评价

本研究以 160 bp 增强子序列为对象，构建基于 DDPM 的序列生成与评价流程。原始数据包含 11,985 条序列，按 ACGT 字符筛选后保留 11,984 条唯一序列。两个已有训练实例分别记为 DDPM-A 和 DDPM-M，均基于同一完整序列来源分别随机划分后开展无条件训练，活性标签未作为生成模型的条件输入。两个实例各保存 40 个 checkpoint，每个 checkpoint 的既有生成集合均包含 9,000 条合法的 160 bp 序列。为分析已经用于后续引导研究的模型，本节比较两个实例 epoch 2000 的生成结果与同等规模的 9,000 条真实参照序列；完整 checkpoint 记录列于补充材料。

生成序列与真实参照序列在碱基组成上呈现相近的分布，但两个训练实例保留了不同程度的 GC 偏移。真实序列的平均 GC 含量为 38.61%，DDPM-A 和 DDPM-M 分别为 40.92% 和 38.18%；对应的序列间标准差分别为 7.92、8.54 和 7.94 个百分点（Fig. 1A）。随着 k 从 3 增加至 6，DDPM-A 与真实序列的 k-mer 频率 PCC 由 0.9482 变化至 0.9297，DDPM-M 则由 0.9166 变化至 0.8769（Fig. 1B–C）。这些结果说明生成集合保留了真实序列的主要局部组成规律，同时较长片段的频率关系仍存在偏差。

统一的 JASPAR 2024 植物 motif 扫描进一步用于评价生成序列的调控模式组成。真实集合中检测到 346,153 次 motif 命中，DDPM-A 和 DDPM-M 分别为 281,531 和 279,293 次。以三个集合中命中过的 704 个 motif ID 为共同基准，生成与真实集合的命中次数分布 PCC 分别为 0.9607 和 0.9524。按旧评价实现重计数 motif 中心位置后，DDPM-A 和 DDPM-M 相对真实集合的加权一维 Wasserstein 距离分别为 0.9850 bp 和 1.5875 bp（Fig. 1D）。motif 类型组成与位置分布反映两个不同层面的特征；位置距离较小并不说明所有 motif 的频率或功能相同，生成集合的总命中数也低于真实参照。

两个生成集合的 9,000 条序列均无完全重复，且与完整的 11,984 条真实序列均无正向序列的完全匹配。随机抽取 100,000 对不同记录比较其按位 Hamming identity，真实集合、DDPM-A 和 DDPM-M 的均值分别为 0.2640、0.2594 和 0.2727（Fig. 1E）。含至少 10 bp 同聚物的序列比例分别为 5.69%、3.52% 和 4.48%；至少 20 bp 同聚物的数量分别为 13、2 和 0 条（Fig. 1F）。该结果支持生成集合具有组成层面的分布一致性与集合内部的序列变化，但完全匹配检查尚不足以排除近似拷贝。真实参照来源于模型数据来源的完整集合，也不能替代独立测试集上的泛化评价。

## Results 2. 预测器引导下的增强子定向生成

为研究 DDPM 序列生成的可控性，本研究分别分析拟南芥 35S DOWN 的引导方法比较，以及玉米 35S UP、DOWN 和 BOTH 的 checkpoint 扫描。UP 和 DOWN 对应原始数据中的上游与下游实验条件，两个名称均不表示分数优化的相反方向。训练日志记录的拟南芥 DOWN 预测器测试 PCC 为 0.6948；玉米 UP 和 DOWN 分别为 0.4880 和 0.7434。完整可比较真实集合的玉米 UP/DOWN 重预测 PCC 为 0.8921/0.7728，但这组 11,969 条记录包含模型训练数据来源，不作为独立测试表现。以下生成结果描述预测器评分的变化，尤其玉米 UP 的预测可靠性需结合其测试表现解释。

在 DDPM-A 的 epoch 2000 上，五种拟南芥 DOWN 引导方法分别与 100 条无引导序列比较，使用共同初始噪声和 seed 42。无引导序列的平均预测分数为 3.9671；直接最大化、在无噪声估计上求梯度、Adam 梯度、正弦调度和采样后额外梯度更新的均值变化分别为 +0.3379、+0.7519、−0.4269、+0.1567 和 +0.9534（Fig. 2A）。采样后更新方法的平均分数为 4.9206，100 对序列中有 88 对的引导后分数更高（Fig. 2B）。相比之下，Adam 梯度方法仅有 24 对改善，且群体均值下降，说明不同梯度更新策略在该模型上并非都产生正向效果。该比较来自单个种子，后续反向扩散噪声未被逐步配对，不能据此推断跨种子的稳定增益。

玉米方向控制实验使用 DDPM-M 的 40 个 checkpoint，每个 checkpoint 分别进行 UP、DOWN 和 BOTH 引导，各生成 500 条序列，共获得 60,000 条逐序列预测记录。三种模式分别最大化上游分数、下游分数和二者之和，引导强度为 0.5，预测器输入的 softmax 温度为 0.1。以 epoch 1500 为探索性例子，UP 模式的上游／下游预测均值为 11.0581／6.0134，DOWN 模式为 4.6408／9.3895，BOTH 模式为 10.3691／8.2215（Fig. 2D–E）。单方向优化表现出两个维度之间的取舍，BOTH 组的两维平均分数之和高于两种单方向组。该扫描没有匹配的无引导逐行对照，因此不能从这些模式间差异直接计算相对无引导的增益。

双目标达标率对评价阈值与 checkpoint 均具有敏感性（Fig. 2C）。使用历史 35S 子集预测最大值阈值，即 UP > 11.161853790283203 且 DOWN > 6.437514305114746，BOTH 模式的最高双达标数量为 epoch 1300 的 246/500（49.2%）。在历史 relaxed 阈值（UP > 10、DOWN > 6.5）和 strict 阈值（UP > 10、DOWN > 7）下，最高数量均出现在 epoch 1500，分别为 371/500（74.2%）和 359/500（71.8%）。这些阈值用于生成后重评价，不是原始运行成功的同一标准。原始生成日志所用的 61 条参考序列最大值阈值为 12.4793／9.1759，epoch 1500 BOTH 组在这一标准下双达标为 0/500。因此，不同阈值下的最高比例不能互相替代，也不构成最终 checkpoint 的自动选择依据。

高联合预测分数同时伴随明显的序列复杂度问题。epoch 1500 的 UP、DOWN 和 BOTH 组中，含至少 20 bp 同聚物的数量分别为 9、495 和 373 条（Fig. 2F）。在 BOTH 组的 359 条 strict 双达标序列中，只有 76 条未出现至少 20 bp 同聚物，占全部生成序列的 15.2%；满足这一描述性长度限制的集合共有 127 条，其双达标比例为 59.84%。相同检查下，epoch 1300 BOTH 组保留 481 条，其中 229 条同时超过 strict 阈值，占全部生成序列的 45.8%。这表明仅按预测达标数选择 checkpoint 可能偏向复杂度异常的输出。长度 20 bp 在这里是事后敏感性检查条件，最终质量门槛仍需与候选序列的其他性质共同确定。预测器引导的计算收益因此需要与序列质量并行评价，并接受独立模型或功能实验的进一步检验。

## Computational Methods

### 数据、表示与训练实例

生成模型使用 NG_enhancer_data.csv 中的 Sequence 列。文件包含 11,985 条 160 bp 记录；严格 ACGT 筛选保留 11,984 条唯一序列。数据加载器将序列编码为 A、C、G、T 顺序的 one-hot 张量，单条形状为 4 × 160。虽然配置分别指定 Arabidopsis_35S_DOWN 或 Maize_35S_DOWN 标签列，训练循环仅使用序列，未将标签输入模型或损失。为区别两个已有训练实例，本文记为 DDPM-A 和 DDPM-M；这些标识不表示按物种标签筛出的序列子集，各自实际训练划分的成员未能恢复。实例来源、配置及现存权重校验信息记录于 Table S1。

已读取的训练配置按 0.9／0.1 进行随机划分，但训练代码未使用验证集计算模型选择指标。配置中的 seed 42 只用于 Python random，未用于 torch.random_split 或模型初始化，也未保存划分索引。因此，本次核验不能恢复原始训练／验证成员。组成评价使用既有的 real_9000.fasta，其来源为同一完整序列集合的抽样；它作为真实分布参照，不作为独立于训练集的测试数据。

### DDPM 训练与采样

DDPM 通用框架参考 Ho 等[1]。本研究实现采用一维 UNet，输入输出均为 4 通道；初始通道数为 16，编码阶段通道配置为 16→32→64→128→128，包含残差块、线性注意力、瓶颈注意力及跳跃连接。时间编码使用 128 维正弦表示，经 MLP 映射为 256 维。前向过程采用 1,000 步线性噪声调度，β 从 0.0001 增加到 0.02，以真实噪声与预测噪声的均方误差训练。Adam 学习率为 1×10⁻⁴，weight decay 为 1×10⁻⁵，batch size 为 64，训练 2,000 epochs，每 50 epochs 保存权重。两个实例的现存训练日志均记录至 epoch 2000。

无引导采样从标准高斯噪声开始，执行 1,000 步反向扩散；每个保存的 checkpoint 按 90 批、每批 100 条生成 9,000 条序列。连续输出在每个位点按通道 argmax 解码为 ACGT。代码仅设置 Python 随机种子，不能据此声称全部采样随机流可重现。本次逐文件核对两个实例的 80 个生成集合，共 720,000 条序列，均为合法的 160 bp 输出。主文组成分析使用两个实例 epoch 2000 的既有结果，完整扫描保留于补充材料，不把它们当作独立种子重复。

### 活性预测器

预测器采用残差卷积、位置编码、6 层 TransformerEncoder、卷积降维和全连接回归。Transformer 的 d_model 为 64，注意力头数为 8，前馈维度为 128；回归层为 160→64→1，中间使用 GELU 和 dropout 0.25。输入为 one-hot 序列，输出直接回归所选标签列，已读取代码未实施额外标签变换。模型以 MSE 和 Adam 训练，根据验证集 PCC 保存最优权重。玉米 UP／DOWN 配置分别使用 seed 45／42，batch size 64、100 epochs、weight decay 1×10⁻⁴，学习率分别为 1×10⁻³／5×10⁻³。

玉米 UP 的训练／验证／测试样本数为 9,580／1,197／1,198，DOWN 为 9,581／1,197／1,199；拟南芥 DOWN 为 9,571／1,196／1,197。预测器训练代码使用带指定种子的 torch.Generator 划分，各模型因缺失标签过滤及种子不同而具有不同划分。2026年10月8日另行对八份固定预测权重执行CPU评价。七个新版预测器按当前数据、配置种子和日志数量重建测试集，整体PCC四位小数与训练日志一致。Ara UP经作者确认，按现存旧代码的序列字典筛选及seed42重建，有效样本11,971条，训练／验证／测试为9,577／1,197／1,197；固定best_model.pt的整体PCC为0.7507，MSE为0.929766。旧日志0.7529为不同实现下的批次PCC平均值，不作为当前权重整体PCC。八项均已记录数据、权重、有序测试成员及源码哈希；原始划分索引未保存，重建结果不等同恢复了历史测试成员，Ara UP的历史训练排除关系尤其不能完全确认。针对完整可比较数据的重预测相关性单独记录，不与测试集表现混用。

### 两轮引导实验

梯度引导的通用思想参考 Dhariwal 与 Nichol[2]，本文实际实现以回归预测器提供目标信号。拟南芥 DOWN 方法比较使用 DDPM-A epoch 2000 和对应 DOWN 预测器，各方法生成 100 条无引导与 100 条引导序列。seed 42 对应共同初始噪声；后续采样随机流未重置，不能视为逐步噪声完全匹配。引导作用于反向扩散的末段 200 步（t < 200），基础强度为 500。直接最大化、无噪声估计梯度、Adam 梯度和正弦调度分别改变梯度计算位置或更新形式。Adam 的 β₁／β₂为 0.9／0.999，ε为 10⁻⁸；正弦强度为 500 sin[π(1−t/200)/2]。采样后更新方法结合目标值 7.0 的 MSE 引导和步长 0.5 的预测分数梯度更新。基础条件梯度在 DDPM 后验均值上经后验方差缩放，采样后更新再对当前状态追加梯度步。这五种方法构成不同的既有设置，比较结果不解释为仅改变一个变量的严格消融。

玉米扫描使用 DDPM-M epoch 50–2000、间隔 50 的 40 个 checkpoint，并对每个 checkpoint 运行 UP、DOWN 和 BOTH 三种模式，各 500 条。代码同时设置 Python、NumPy 和 PyTorch seed 42；生成 batch 为 100，评分 batch 为 256。每个反向步骤将无噪声估计经温度 0.1 的通道 softmax 输入预测器，目标分别为上游分数、下游分数和两个分数之和。采样后对当前噪声状态的目标梯度以 0.5 倍直接追加，两个目标没有额外标准化权重。该方法与拟南芥方法比较的方差缩放更新不同，二者分开统计。引导器与评分器使用同一组模型，未形成独立预测器验证。

### 序列组成、motif 与多样性

GC 为每条序列的 G/C 数量除以 160。k-mer 分析使用 k=3、4、5、6，只统计输入正向链的重叠窗口，不合并反向互补；各集合以窗口总数归一化，并在完整 4ᵏ 词表上计算生成与真实频率向量的 PCC。集合内部多样性通过每组有放回抽取 100,000 对不同记录，以按位相同碱基比例计算 Hamming identity，抽样 seed 为 42。图中区间是样本对 identity 的 5%–95% 分位数，不是独立运行的置信区间。完全匹配分析以完整 11,984 条真实序列为参照；近似序列搜索及反向互补匹配未包含在本轮分析中。

motif 扫描使用既有 JASPAR 2024 CORE plants non-redundant 文件[3]与 FIMO 5.4.1[4]；四份现存扫描 XML 均记录双链扫描、p 值阈值 1×10⁻⁴、矩阵伪计数 0.1 和背景参数 --bgfile --nrdb--。本次没有重新运行 FIMO，而是对现存命中表重计数。motif 身份分布在真实与两个 epoch2000 集合中命中过的 704 个 motif ID 联合集合上补零后计算命中次数 PCC；703 个 alt-ID 类别与 704 个 motif ID 不混用。位置分布沿用旧实现，以 floor[(start+stop)/2] 映射到 0–159 的索引，每个位点加入伪计数 1。使用该位置索引及命中权重计算一维 Wasserstein 距离，单位为 bp；此指标衡量位置分布，不是 motif 类别的距离。重计数验证了 DDPM-A epoch500 和 epoch2000 的既有等量参照结果。

### 阈值、质量敏感性与统计边界

玉米扫描的后评价分别使用历史 35S 子集预测最大值阈值（11.161853790283203／6.437514305114746）、relaxed 阈值（10／6.5）及 strict 阈值（10／7），均采用严格大于号。relaxed／strict 是历史脚本手工指定的评价条件，其名称不代表已经统计验证的可信界限。原始生成使用的 61 条参考序列最大值阈值（12.479280471801758／9.175949096679688）另行记录，不与上述后评价混用。达标率的分母为每组全部 500 条；同聚物敏感性检查同时报告总分母和保留分母。

同聚物指标为单条序列最长连续相同碱基片段，使用至少 10 bp 和至少 20 bp 两种长度描述。移除至少 20 bp 同聚物后的达标计数属于事后敏感性检查，不作为已经确认的最终生物学质量门槛。本文统计均为现存单次输出集合的描述性结果，不填写缺少独立重复支持的显著性或跨种子误差线。7 月 8 日的现存预测表与同目录旧摘要存在版本冲突，相关旧计数不纳入主文性能主张。权重 SHA256 对应本次读取的当前文件，不能证明历史运行时文件内容未发生变化。重分析代码、聚合数据和来源清单随稿件整理，最终模型与阈值选择仍需作者确认。
