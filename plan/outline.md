# 已确认的计算部分结构

用户在本次会话确认仅保留两个 Result，并要求参照另一篇论文的叙述方式整理。

## Results 1：DDPM 生成的 160 bp 增强子序列质量评价

段落链：生成与评价对象 → GC / k-mer 分布 → motif 分布 → 多样性、新颖性和低复杂度。

每段应写出条件、样本数、指标、数值及对应图表。未经核实的数值用唯一缺口编号标记。只有真实数据支持时才能把标题改为结论式标题。

## Results 2：预测器引导下的增强子定向生成

段落链：预测器测试表现 → 无引导 / UP / DOWN / BOTH 对照 → 双目标达标 → 引导参数影响 → 引导后质量变化。

UP/DOWN 为待核实的实验条件名称，暂不解释为增强或抑制。主结果不自动选用历史最好 checkpoint 或最高达标数量。

## 配套材料

Methods 按输入数据、编码、DDPM、预测器、引导、指标、统计的顺序描述数据流。Figure 1/2 图注与面板定义和 Results 对应。历史阈值复盘、checkpoint 扫描及预测器表现作为候选补充证据。独立 motif 插入及两个基因案例不纳入当前主文。
