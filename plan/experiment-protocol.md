# 实验协议：尚待冻结

本文件整理核对口径，不表示已执行新实验。

## 数据与划分

训练数据必须由用户确认，候选 NG_enhancer_data.csv 不能自动成为最终数据。核实筛选规则、160 bp 长度、碱基合法性、重复处理、样本数、物种和条件。训练 / 验证 / 测试集的划分策略及跨集合近重复需要记录；质量评价的真实参照集须说明是否独立于训练集。

## 模型与对照

主线为用户选择的 DDPM。冻结架构、代码版本、训练超参数、checkpoint 标识和哈希。UViT、DiT 等资产不自动作为公平基线；只有数据、样本数和评价协议可比时才纳入。生成质量可先以真实参照序列与无引导 DDPM 比较。

引导对照包括无引导、UP、DOWN、BOTH。优先使用相同初始噪声及随机种子的配对设计；若历史实验不配对，改用独立样本统计并标明。每个物种、模型、阈值口径单独分组。

## 指标

Result 1：GC 分布、固定 k 的 k-mer 频率相关性、motif 命中分布 / Wasserstein、内部相似度、对训练集及独立参照集的相似度、唯一序列比例、同聚物与复杂度。

Result 2：UP/DOWN 预测分布、配对差值或独立样本差异、目标达标比例、双达标比例、质量变化。报告全部生成样本的指标与质量过滤后指标及过滤保留率，避免只展示筛中序列。

## 阈值与统计

阈值源集合、筛选方法、实测或预测来源、单位及比较符号必须冻结。不同阈值的结果不可直接排序。缺少可信阈值时只报告连续分数变化。

随机种子与独立重复数量待核实。序列级样本量不替代独立运行数量。报告均值 / 中位数、离散程度和适合设计的置信区间；检验、效应量、重复层级及多重比较处理待核实，不能预填 p 值。

## 参数、稳健性与效率

已有 epoch sweep、引导方式与阈值复盘先按同一协议整理，主图可仅呈现最终配置及少量必要参数。完整扫描放补充材料。采样步数、引导强度、耗时、硬件与显存只有日志支持时报告。

没有新增模块贡献时不强行添加消融实验。模型比较、消融、跨物种泛化和独立预测器验证只有现有结果完整或用户另行授权时纳入。当前主线不把解释性分析列为独立贡献。

## 结论边界

结果限于计算生成质量与预测器评分的定向变化。未取得独立实验数据时不宣称真实增强子活性提高。与指导模型相同的评价器容易受模型偏好影响，该限制需保留。
